**This template is only compatible with Mango version 0.18.0 or higher.**

The built-in Mango template generates border colors for regular, active, split, and urgent windows, and colors for jump label, and group bar borders, as well as the scratchpad background, root window background, and drop shadow of dragged windows.

## Setup

Enable **Mango** under **Settings → Templates → Compositors**.

OKARU writes the rendered template to `~/.config/mango/okaru.conf` and appends the line `source=~/.config/mango/okaru.conf` to `~/.config/mango/config.conf` when that config already exists and is writable. These paths honor `$XDG_CONFIG_HOME`. If the Mango setting `auto_reload_config` is enabled, Mango reloads both files automatically when they change.

If the primary user config is absent, OKARU leaves it absent and warns that manual setup is required. Add the source line to the config Mango actually loads. Use the resolved absolute path to `okaru.conf` when editing a system or custom config, and edit the managing source for declarative configs. See [Compositor Configuration](/okaru/theming/app-theming/#compositor-configuration) for setup and recovery instructions.
