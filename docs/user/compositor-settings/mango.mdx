Configure Mango for OKARU surfaces and use Mango binds to launch OKARU IPC commands directly from the compositor.

The examples below use Mango's `.conf` format, which is supported in Mango 0.18.2. Mango also supports `~/.config/mango/config.toml`; when both files exist, `config.conf` takes precedence. For TOML, place settings and `exec_once` under `[global]`, and keybinds under `[bind.default]`. See Mango's [TOML conversion guide](https://github.com/mangowm/mango/blob/main/docs/configuration/toml.md) for the corresponding syntax.

## Autostart OKARU

Add to your `~/.config/mango/config.conf`:

```bash
exec_once=okaru
```

## Blur and shadows

The configuration below uses Mango's shadows instead of OKARU's. It disables compositor blur behind bars and panels with `blur_layer=0`, while keeping blur enabled for application windows.

Add this to `~/.config/mango/config.conf`:

```ini
blur=1
blur_layer=0
blur_optimized=1
blur_params_num_passes=2
blur_params_radius=5
blur_params_noise=0.02
blur_params_brightness=0.9
blur_params_contrast=0.9
blur_params_saturation=1.0
layer_animations=0

shadows=1
layer_shadows=1
shadow_only_floating=0
shadows_size=4
shadows_blur=12
shadows_position_x=2
shadows_position_y=2
shadows_color=0x000000ff
```

Mango uses `blur_layer` for layer-surface blur and `layer_shadows` for layer-surface shadows. Use those exact names; both also require their global toggles, `blur=1` and `shadows=1`.

Then disable OKARU's rendered drop shadows in your OKARU TOML config:

```toml
[bar.default]
shadow = false
contact_shadow = false

[dock]
shadow = false

[shell.panel]
shadow = false
```

If you have more than one bar, set `shadow = false` and `contact_shadow = false` on each `[bar.<name>]` entry.

## IPC Keybinds

Add these binds to your `~/.config/mango/config.conf`:

```bash
# Core binds
bind=SUPER,space,spawn,okaru msg panel-toggle launcher
bind=SUPER,s,spawn,okaru msg panel-toggle control-center
bind=SUPER,comma,spawn,okaru msg settings-toggle

# Media keys
bind=NONE,XF86AudioRaiseVolume,spawn,okaru msg volume-up
bind=NONE,XF86AudioLowerVolume,spawn,okaru msg volume-down
bind=NONE,XF86AudioMute,spawn,okaru msg volume-mute
bind=NONE,XF86MonBrightnessUp,spawn,okaru msg brightness-up
bind=NONE,XF86MonBrightnessDown,spawn,okaru msg brightness-down
```
