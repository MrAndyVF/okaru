`okaru-launcher` is a small, fast search card in the spirit of Raycast/oma-cast. It searches your applications and a short
list of shell commands, and shows your keyboard shortcuts. Open it with **Super + Space** (or **Alt + Space**).

## Layout

- A large search field with the OKARU mark.
- With nothing typed: **Suggestions** (the apps you use most), **Commands** and **Applications** (alphabetical).
- While typing: a single **Results** section, ordered by match quality nudged by how often you use each result.
- Each row shows the icon, the name, a dimmed description and its kind (Application or Command) on the right.
- The footer shows the available keys drawn as keycaps.

### Styles

`shell.launcher.style` (Settings → Launcher → Style):

- `card` (default): the card above, with suggestions visible as soon as it opens.
- `spotlight`: only a slim search bar near the top of the screen; the list unfolds downward when you start typing and
  folds back when the field is empty again. The keyboard-shortcut view and dmenu pickers are always unfolded.

## Keys

| Key                              | Action                                                         |
| -------------------------------- | -------------------------------------------------------------- |
| `Enter`                          | Open the result. For an app that is already running, focus its window |
| `Shift+Enter`                    | Open a new window of the app                                   |
| `Up` / `Down`, `Ctrl+N` / `Ctrl+P`, `Ctrl+J` / `Ctrl+K` | Move the selection                  |
| `Page Up` / `Page Down`          | Move eight rows                                                |
| `Esc`                            | Close (in the shortcut view opened from the launcher: go back) |

## Commands

The **Commands** section opens parts of the shell: Keyboard shortcuts, Settings, Emojis (`okaru-emoji`), Clipboard,
Session and Wallpapers. They are found by name or keyword in English and Spanish ("power", "apagar", "fondo"…).

## Keyboard shortcuts view

Choose **Keyboard Shortcuts**, or press **Super + /** to open it directly (`okaru msg panel-toggle launcher ":keybinds"`).
It does not list every bind: it shows a curated list of OKARU's built-in functions (apps, OKARU panels, windows,
screenshots, session) with short descriptions, each with the keys **you** bound to it. Binds are recognized by what
they do, so changing a key in Settings or in `binds.lua` updates the view. Your own binds appear under **Your
shortcuts** when they carry a `description`:

```lua
hl.bind("SUPER + G", hl.dsp.exec_cmd("gimp"), { description = "GIMP" })
```

The view reads Hyprland's Lua binds, so it is available on Hyprland only.

## Dmenu mode

`okaru dmenu` is a stdin/stdout picker for scripts that already produce newline-separated choices:

```sh
printf 'alpha\nbeta\ngamma\n' | okaru dmenu -p "Pick"
```

It opens the launcher scoped to those candidates, prints the selected line to stdout, and exits `0`. Closing the
launcher or pressing Escape prints nothing and exits `1`. `-p` / `--prompt` sets the launcher input placeholder for that
picker. A tab inside a candidate splits the display into title and description, but the full original line is still
returned. If the current filter has no candidate match, pressing Enter returns the typed text.

The command talks to the running OKARU instance on the same `XDG_RUNTIME_DIR` and `WAYLAND_DISPLAY`; start OKARU first,
then call `okaru dmenu` from scripts or compositor commands.

## Text editing shortcuts

When `shell.readline_shortcuts` is enabled (Settings → Shell → General), every text field, including the launcher input, supports readline-style shortcuts. Otherwise `Ctrl+A` selects all and `Ctrl+U` clears the field.

| Shortcut            | Action                                  |
| ------------------- | --------------------------------------- |
| `Ctrl+A`            | Move caret to start of line             |
| `Ctrl+E`            | Move caret to end of line               |
| `Ctrl+B` / `Ctrl+F` | Move caret back / forward one character |
| `Alt+B`             | Move caret to start of previous word    |
| `Alt+F`             | Move caret to end of next word          |
| `Ctrl+W`            | Delete previous word                    |
| `Ctrl+U`            | Clear backward to start of line         |
| `Ctrl+K`            | Delete from caret to end of line        |
| `Alt+D`             | Delete next word                        |

## Configuration

```toml
[shell.launcher]
style       = "card"  # card | spotlight
width       = 760     # card width in pixels (spotlight is capped at 640)
track_usage = true    # remember what you open, for Suggestions and ordering
auto_paste  = "auto"  # paste shortcut used by okaru-emoji: off | auto | ctrl_v | ctrl_shift_v | shift_insert
```

Settings → Launcher has the same options and a button to forget the usage history.
